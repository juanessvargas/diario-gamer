# Diario de Progreso Gamer

Proyecto de Desarrollo Web 3 - USFQ.

Aplicación web para registrar videojuegos,
sesiones de juego y consultar el progreso
calculado de cada videojuego.

## Tecnologías

Backend:
- Node.js
- Express
- TypeScript
- Mongoose
- MongoDB Atlas

Frontend:
- React
- TypeScript
- Vite

Despliegue:
- Render

## Estructura

- backend: API REST y conexión a MongoDB.
- frontend: interfaz de usuario con React.

## Bitácora

El desarrollo se realizará en una rama
de trabajo, con commits por cada capa
y funcionalidad implementada.
